# Gemini AI Coding Assistant

A Streamlit-based AI coding assistant powered by Google Gemini.

## Features

- Chat with Gemini for coding help
- Debug, explain, refactor, and document code
- Generate unit tests from pasted code
- Adjustable model and creativity settings

## Requirements

- Python 3.10+
- A Google Gemini API key

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run gemini_code_buddy.py
```
